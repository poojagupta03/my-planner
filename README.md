# 🌸 My Pretty Planner

A cute, pastel **study-friendly planner** that I built for my personal use. Save your tasks with a time, and get an alarm and notification when it's time to start! ✨

## 🔗 Live Demo
👉 https://poojagupta03.github.io/my-planner/

## 📸 Screenshot
(Yahan apni photo drag and drop karo)

## ✨ Features
- ⏰ **Reminders with alarm**: sound, vibration and notification
- 📚 **Categories**: Study, Personal, Exam
- 🔁 **Daily repeat** and 5 min **snooze**
- 🍅 **Pomodoro focus timer** (25 min, 45 min, 5 min break)
- 📊 **Daily progress ring** to track completed tasks
- 📓 **Quick notes** for formulas and ideas
- 🌙 **Auto dark mode**
- 📱 Mobile friendly, can be added to the home screen

## 🛠️ Built With
- HTML
- CSS
- JavaScript

## 🚀 How to Use
1. Open the live demo link
2. Tap **Notifications on karo** and allow notifications
3. Add a task with date and time
4. Get an alarm when the time comes 🔔

On your phone, use **Add to Home Screen** to use it like an app.

## 📝 Note
All reminders and notes are saved locally in your browser, so your data stays private.
Alarms work best when the app is open or running in the background.
